# Шагающий самолёт «Топот»

Реализация замороженного контракта **SPEC.md 1.0** от 8 ноября 2026 года.

Автор ТЗ и тестов — Васильев Савелий Александрович (роль A).
Разработчик — Ивчук Михаил Петрович (роль D).

«Топот» — наземный самолёт на механических ногах. Он ходит по дороге и
пересечённой местности, перешагивает препятствия, заправляется и ремонтирует
ноги. Крылья нужны для равновесия: летать и плавать аппарат не умеет.

## Запуск

Нужен **Python 3.10+**, сторонних зависимостей нет. Проверено на Python 3.12.14.
Команды выполняются из корня проекта, где лежит `walking_plane.py`.

```bash
python -m unittest discover -s tests -t . -v
```

Результат проверки разработчика: **20 тестов, OK** — 16 модульных и
4 сценарных. В Windows вместо `python` можно использовать `py -3`.

`walking_plane.py` — библиотечный модуль, отдельного графического интерфейса
или интерактивного приложения в контракте нет.

## Пример использования

```python
from walking_plane import PlaneUnsupportedTerrain, WalkingPlane

plane = WalkingPlane(
    name="Топот",
    mass_kg=1000,
    leg_length_m=2,
    max_speed_kmh=20,
)

print(plane.move(5, "road"))   # 0.25 часа, энергия 90
print(plane.move(3, "rough"))  # 0.3 часа, энергия 78
if plane.can_step_over(1):
    plane.step_over(1)         # энергия 68, позиция не меняется
print(plane.move(2, "road"))   # 0.1 часа
print(plane.position_km)       # 10.0 км
print(plane.energy)            # 64.0

before = plane.get_status()
try:
    plane.move(1, "air")
except PlaneUnsupportedTerrain:
    print("Топот не летает")
assert plane.get_status() == before
```

## Публичный интерфейс

```text
WalkingPlane(name, mass_kg, leg_length_m, max_speed_kmh, energy=100.0)
```

Имя должно содержать непробельный символ; пробелы по краям сохраняются.
Масса, длина ног и скорость положительны, энергия находится в диапазоне
0…100. Масса информационная и в расходе не участвует.

| Метод | Результат и изменение состояния |
|---|---|
| `move(distance_km, terrain)` | Возвращает часы, увеличивает путь, расходует энергию |
| `calculate_energy(distance_km, terrain)` | Возвращает расход без изменения состояния |
| `can_step_over(height_m)` | Возвращает возможность манёвра без изменения состояния |
| `step_over(height_m)` | Тратит энергию, позицию сохраняет; возвращает `None` |
| `refuel(amount)` | Пополняет энергию до 100; возвращает `None` |
| `damage_legs()` | Повреждает ноги; возвращает `None` |
| `repair_legs()` | Бесплатно ремонтирует ноги; возвращает `None` |
| `get_status()` | Возвращает независимый обычный словарь состояния |

На дороге скорость равна `max_speed_kmh`, расход — 2 единицы на километр.
На пересечённой местности скорость вдвое меньше, расход — 4 единицы.
Предел высоты равен половине длины ног, расход на манёвр — `height_m * 10`.
Достаточность энергии учитывает абсолютный допуск `1e-7`, заданный в SPEC.

Восемь атрибутов доступны только для чтения: `name`, `mass_kg`,
`leg_length_m`, `max_speed_kmh`, `max_step_height_m`, `energy`,
`position_km`, `legs_intact`. Присваивание и удаление вызывают
`AttributeError`. Состояние меняют только предусмотренные методы.

Все доменные ошибки наследуют `WalkingPlaneError`, затем `CrazyVehicleError`:
`PlaneUnsupportedTerrain`, `PlaneLegsDamaged`, `PlaneObstacleTooHigh`,
`PlaneNoEnergy`. Неверные типы вызывают `TypeError`, неверные значения
и непредставимые конечным `float` результаты — `ValueError`.
При отказе всё публичное состояние сохраняется. Порядок проверок соответствует
SPEC.
